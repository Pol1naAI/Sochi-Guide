# Sochi in 3 Days

An English-language travel guide for first-time visitors to Sochi.

## About the Project

The website presents a three-day itinerary:
- Day 1: Central Sochi and the seaside.
- Day 2: Olympic Park and Sirius.
- Day 3: Krasnaya Polyana and the mountains.

Each day includes a photograph, suggested activities and restaurant links to Google Maps.

## Technologies

- HTML5 for page structure and content.
- CSS3 for styling.
- Media queries at 900px and 600px for responsive design.

## How to View

Download the project and open index.html in a browser.

## Project Structure

- index.html - page structure and content.
- style.css - website styling.
- images/ - photographs used on the website.
- README.md - project documentation.
